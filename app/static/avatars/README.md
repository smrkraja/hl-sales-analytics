# Profile pictures

The banner shows, in order of preference:

1. The photo from the identity provider (`picture` claim - Google and Okta usually send one).
2. Dev mode only: your own local photo at `app/static/avatars/me.jpg` (or `me.png`).
   It is gitignored, so it never leaves your machine.
3. `default.jpg` - a stock headshot.
