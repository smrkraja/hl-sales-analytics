# Landmark banner images

The sign-in banner shows the landmark of the city the user signed in from. Images
are registered in `hl/core/landmarks.py`. Add a city: drop a wide (~3.5:1, 1920px)
image here and add one entry to `LANDMARKS`. Only use images licensed for reuse.
